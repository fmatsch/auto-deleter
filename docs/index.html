Auto Deleter

Löscht Ordnerinhalte automatisch nach konfigurierbaren Intervallen – stündlich, täglich oder wöchentlich. Läuft wahlweise als Windows-Dienst im Hintergrund.

⬇ Für Windows herunterladen Quellcode auf GitHub
Windows 10 / Server 2016 oder neuer · .NET 6 (self-contained) · kostenlos, MIT-Lizenz

So richtest du es ein

  1. StartenAutoDeleter.exe als Administrator ausführen – der UAC-Dialog erscheint automatisch.
  2. Ordner hinzufügenMit „＋ Ordner hinzufügen" einen oder mehrere Ordner eintragen.
  3. Intervall wählenFür jeden Ordner Stündlich, Täglich oder Wöchentlich wählen.
  4. Optional: Dienst„Als Windows-Dienst" aktivieren – der Dienst läuft dann auch ohne offenes Fenster.

Funktionen

Flexibler Zeitplan

Stündlich, täglich oder wöchentlich – pro Ordner einzeln einstellbar.

Windows-Dienst

Einmal aktiviert, läuft der Dienst im Hintergrund und startet automatisch mit Windows.

Dateien in Verwendung

Dateien, die ein anderer Prozess geöffnet hält, werden übersprungen – kein Fehler, kein Absturz.

Sofort leeren

„Alle Ordner sofort leeren" löscht alle konfigurierten Ordner unmittelbar, ohne auf den nächsten Zeitpunkt zu warten.

Unterordner aufräumen

Dateien werden rekursiv gelöscht; leere Unterordner verschwinden danach automatisch.

Live-Konfiguration

Der Dienst liest die Konfiguration jede Minute neu – Änderungen über die GUI werden sofort übernommen, ohne Neustart.

Gut zu wissen

Die Konfiguration wird unter C:\ProgramData\AutoDeleter\config.json gespeichert und ist für Dienst und GUI gemeinsam.

Der Dienst kann auch manuell über die Dienstverwaltung (services.msc) oder sc stop/start AutoDeleter gesteuert werden.

  • Administrator-Rechte: Werden für die Service-Installation benötigt. Die App fordert sie per UAC-Dialog automatisch an.
  • SmartScreen: Die Exe ist nicht code-signiert, Windows warnt beim ersten Start. Sie wird bei jedem Release öffentlich auf GitHub aus dem Quellcode gebaut.
  • Bauen: dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true – benötigt nur das .NET 6 SDK.
